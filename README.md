# Практичні заняття з кросплатформного програмування

Цей репозиторій містить практичні завдання, програмний код та навчальні матеріали, розроблені відповідно до тем практичних занять навчальної дисципліни **«Кросплатформне програмування»**.

## Навчальна дисципліна

Дисципліна **«Кросплатформне програмування»** базується на вивченні мови програмування **Java** та практичному застосуванні її можливостей для розробки програмного забезпечення.

Усі практичні завдання, приклади програмного коду та навчальні проєкти, представлені в цьому репозиторії, орієнтовані на використання мови програмування **Java**.

У процесі виконання практичних робіт послідовно вивчаються та закріплюються основні можливості мови Java, принципи об'єктно-орієнтованого програмування, робота з колекціями, файлами, потоками, мережею та іншими технологіями, передбаченими програмою навчальної дисципліни.

## Структура репозиторію

Кожному практичному заняттю відповідає окрема директорія:

- `2.1-...` — практичне заняття № 2/1
- `2.2-...` — практичне заняття № 2/2
- `2.3-OOP` — практичне заняття № 2/3
- `...` — наступні практичні заняття

У відповідних директоріях зберігаються:

- умови практичних завдань;
- навчальні матеріали;
- програмний код мовою Java;
- покрокові інструкції щодо виконання завдань;
- додаткові матеріали та приклади.

## Призначення репозиторію

Репозиторій призначений для систематизованого зберігання матеріалів практичних занять та програмного коду, що розробляється в процесі вивчення дисципліни **«Кросплатформне програмування»**.

Матеріали організовані відповідно до послідовності практичних занять, що дозволяє поступово формувати та закріплювати практичні навички програмування мовою **Java**.
