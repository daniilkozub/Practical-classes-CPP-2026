# Практичні заняття з кросплатформного програмування

Репозиторій містить практичні завдання розроблені відповідно до тем практичних занять навчальної дисципліни **«Кросплатформне програмування»**.

## Структура репозиторію

Кожному практичному заняттю відповідає окрема директорія:

- `2.1-...` — практичне заняття № 2/1
- `2.2-...` — практичне заняття № 2/2
- `2.3-OOP` — практичне заняття № 2/3

У відповідних директоріях зберігаються:
- умови практичних завдань;
- додаткові матеріали, необхідні для виконання роботи.

## Навчальна дисципліна

**Кросплатформне програмування**

Репозиторій використовується для організації та зберігання матеріалів практичних занять курсу.
