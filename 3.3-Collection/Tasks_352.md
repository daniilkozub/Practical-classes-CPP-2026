## Завдання 1. Склад спорядження

Створіть `enum Category` (`WEAPON`, `AMMO`, `MEDICAL`) і клас `Item` з полями `name`, `category`, `quantity`.

Створіть клас `Warehouse` зі списком `List<Item>`:

- `addItem(Item item)` — додає предмет.
- `getTotal(Category c)` — загальна кількість одиниць у категорії.
- `printAll()` — виводить усі предмети.

## Завдання 2. Журнал оцінок

Створіть клас `GradeBook`, який зберігає оцінки у `Map<String, List<Integer>>` (прізвище → оцінки).

- `addGrade(String name, int grade)` — додає оцінку. Якщо курсанта ще немає — спочатку створює для нього порожній список.
- `getAverage(String name)` — середній бал курсанта.
- `printAll()` — виводить кожного курсанта, його оцінки та середній бал.

## Завдання 3. Журнал підключень

Дано журнал підключень (IP та результат):

```java
String[] log = {
    "10.0.0.5 OK", "10.0.0.7 FAIL", "10.0.0.5 FAIL", "10.0.0.9 OK",
    "10.0.0.7 FAIL", "10.0.0.7 FAIL", "10.0.0.5 OK", "10.0.0.3 FAIL"
};
```

- Розбийте кожен рядок через `split(" ")`.
- Порахуйте кількість `FAIL` для кожного IP у `Map<String, Integer>`.
- Виведіть результат.
- Виведіть «підозрілі» IP — з 3 і більше невдалими спробами.

## Завдання 5. Узагальнений клас

Створіть узагальнений клас `Storage<T>`, всередині якого є `List<T>`:

- `add(T item)` — додає елемент.
- `get(int index)` — повертає елемент.
- `size()` — кількість елементів.
- `printAll()` — виводить усі елементи.

Створіть `Storage<String>` (позивні) і `Storage<Integer>` (номери частот) та перевірте методи.

## Завдання 6. Графік чергувань

Створіть `enum Day` (`MONDAY` … `FRIDAY`) і клас `DutySchedule` з полем `Map<Day, List<String>>` (день → черговий склад).

- `assign(Day day, String name)` — призначає курсанта на чергування. Один курсант не може бути двічі в один день (перевірте через `contains`).
- `printSchedule()` — виводить графік по днях.
- `countDuties(String name)` — скільки разів курсант заступає на чергування за тиждень.
