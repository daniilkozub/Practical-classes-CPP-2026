## Завдання 1. try-catch (0,5)

Створіть дві змінні `int a = 10` і `int b = 0`. Виведіть результат ділення `a / b`.

- Використайте `try-catch`, щоб перехопити `ArithmeticException`.
- У `catch` виведіть: «Ділити на нуль не можна».
- Після `try-catch` виведіть: «Програма працює далі».

> **Коли використовують:** коли код може «впасти» під час виконання, а програма має працювати далі.

## Завдання 4. try-catch-finally (0,5)

Напишіть метод `static void divide(int a, int b)`, який виводить результат ділення `a / b`.

- Усередині методу використайте `try-catch-finally`.
- У `catch` перехопіть ділення на нуль.
- У `finally` виведіть: «Обчислення завершено».
- У `main` викличте `divide(10, 2)` і `divide(10, 0)`.

❓ Чи виконався `finally` в обох випадках?

> **Коли використовують:** коли якусь дію треба виконати завжди, незалежно від того, чи була помилка (закрити файл, вивести підсумок).

- Напишіть метод `setAge(int age)`.

> **Коли використовують:** коли метод отримав неправильні дані і не повинен продовжувати роботу.

## Завдання 6. throws (0,5)

Напишіть метод `static void checkPassword(String password)`.

- Якщо пароль коротший за 8 символів, кидайте `throw new Exception("Пароль занадто короткий")`.
- Додайте до методу `throws Exception`.
- У `main` викличте метод з паролями `"qwerty12345"` і `"123"` у `try-catch`.

❓ Приберіть `try-catch` у `main`. Що скаже компілятор? Поверніть `try-catch` назад.

> **Коли використовують:** коли метод сам не обробляє помилку, а повідомляє тому, хто його викликав: «я можу кинути цей виняток, обробляй його ти».

## Завдання 7. Власний клас винятку (1)

Створіть свій клас винятку `AgeException`:

```java
public class AgeException extends Exception {
    public AgeException(String message) {
        super(message);
    }
}
```

- Напишіть метод `static void checkAge(int age) throws AgeException`, який кидає `AgeException`, якщо вік менший за 18.
- У `main` перевірте вік `25`, `16`, `40` у циклі.

> **Коли використовують:** коли стандартні винятки не описують помилку вашої програми. Назва `AgeException` одразу каже, що сталося.

## Завдання 8. Все разом (2)

Створіть клас `BankAccount` з полем `balance` (`private`) і методом `withdraw(int amount)` (зняти гроші).

- Створіть власний виняток `NotEnoughMoneyException extends Exception`.
- У методі `withdraw`:
  - якщо сума менша або дорівнює 0, кидайте `IllegalArgumentException`;
  - якщо сума більша за баланс, кидайте `NotEnoughMoneyException` (не забудьте `throws`).
- У `main` створіть рахунок з балансом 1000 і спробуйте зняти по черзі суми з масиву `{300, -50, 900, 200}`.
- Використайте `try-catch-finally`: у `finally` виводьте поточний баланс.
