# Практичне заняття № 2/3

**Розробка системи обліку військової техніки із застосуванням принципів ООП у Java**

## Мета роботи

Закріпити практичні навички застосування основних принципів ООП у Java:

| # | Тема |
|---|------|
| 1 | Класи та об’єкти |
| 2 | Інкапсуляція |
| 3 | Абстракція |
| 4 | Наслідування |
| 5 | Перевизначення методів, поліморфізм |
| 6 | `toString()` |
| 7 | `equals()` та `hashCode()` |
| 8 | Перевантаження методів (додатково) |

## Загальна постановка задачі

Розробити невеликий консольний Java-застосунок для обліку військової техніки підрозділу: створювати різні типи техніки, зберігати інформацію про неї та працювати з усіма типами через спільний базовий тип.

> Усі кроки виконуються в **одному проєкті** — кожен наступний крок розширює те, що зроблено на попередньому.

Повний покроковий план з поясненнями — у [ROADMAP.md](ROADMAP.md).

## З чого почати

1. Створіть на комп’ютері порожню папку (наприклад, `vehicle-fleet`).
2. У своїй IDE (IntelliJ IDEA / Eclipse / VS Code) створіть новий проєкт і під час створення вкажіть цю папку як місце його збереження.
3. Рухайтесь по кроках з [ROADMAP.md](ROADMAP.md) послідовно, створюючи потрібні класи.

Консольний Java-проєкт, у якому працюють разом: інкапсуляція, абстракція, наслідування, перевизначення методів, поліморфізм, `toString()`, `equals()` та `hashCode()`.
